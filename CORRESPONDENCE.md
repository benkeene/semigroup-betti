# Correspondence between the informal theorem (claim_0003) and the formal statements

**Informal theorem (agents/shared/claim_0003/CLAIM.md).** Let S = ⟨n₀ < n₁ < n₂ < n₃⟩ be a numerical semigroup with
exactly four minimal generators, w = n₃ − n₀ its width, g = gcd(n₁−n₀, n₂−n₀, n₃−n₀), W = w/g, and β₁(S) the cardinality
of a minimal presentation of S (= μ(I_S), the minimal number of generators of the toric ideal of K[S], any field K). Then
β₁(S) ≤ 2W ≤ 2w.

**The formalized portion of the informal claim (the two upper bounds): formal statements (Challenge.lean, namespace
`SemigroupBetti`).**
```
theorem beta1_le_two_mul_normalizedWidth (K : Type*) [Field K] (n : Fin 4 → ℕ)
    (hpos : 0 < n 0) (hmono : StrictMono n) (hgcd : Finset.univ.gcd n = 1)
    (hmin : MinimallyGenerates n) :
    (toricIdeal K n).spanRank ≤ (2 * normalizedWidth n : ℕ)
theorem beta1_le_two_mul_width … : (toricIdeal K n).spanRank ≤ (2 * (n 3 - n 0) : ℕ)
```
with `toricIdeal K n := RingHom.ker (MvPolynomial.aeval (fun i => (Polynomial.X : K[X]) ^ n i)).toRingHom`,
`MinimallyGenerates n := ∀ i, n i ∉ AddSubmonoid.closure (n '' {j | j ≠ i})`,
`normalizedWidth n := (n 3 - n 0) / Nat.gcd (n 1 - n 0) (Nat.gcd (n 2 - n 0) (n 3 - n 0))`.

**Why they match.**
1. *The semigroup.* A numerical semigroup minimally generated by n₀ < n₁ < n₂ < n₃ is exactly: `n` strictly increasing,
   `0 < n 0` (so all nᵢ > 0), `gcd(n₀,…,n₃) = 1` (numerical = cofinite in ℕ), and no nᵢ in the additive submonoid generated
   by the other three (`MinimallyGenerates`). The hypothesis `0 < n 0` with `StrictMono` gives positivity of all generators.
2. *The toric ideal.* I_S is the kernel of the K-algebra map K[X₀..X₃] → K[t], Xᵢ ↦ t^{nᵢ}; `toricIdeal` is literally this
   kernel (`MvPolynomial.aeval` into `Polynomial K`), as an `Ideal (MvPolynomial (Fin 4) K)`.
3. *β₁.* The informal β₁ is the minimal number of generators of I_S. `Submodule.spanRank I` is the infimum of the
   cardinalities of generating sets of the ideal (Mathlib `Mathlib/Algebra/Module/SpanRank.lean`), i.e. μ(I) as a cardinal.
   The formal inequality `spanRank ≤ ↑(2W)` is therefore "I_S is generated by at most 2W elements", exactly the informal
   bound (no truncation: `spanRank` is a `Cardinal`, not `spanFinrank`).
4. *W and w.* `normalizedWidth n` is w/g computed with ℕ-subtraction and ℕ-division; since n is strictly increasing the
   subtractions are exact; g > 0 (because n₁ − n₀ > 0) and g divides w, so the ℕ-division is exact (g > 0 rules out the
   Lean convention `w / 0 = 0`). `n 3 - n 0` is w.
5. *Fields.* The statement is for an arbitrary field K, as in the informal theorem (the proof is characteristic-free).

**What is and is not formalized.** The informal proof (PROOF_B_combinatorial.md / PROOF_B_lean_writeup.md) proves
(i) the combinatorial invariant β₁ᶜ := Σ_d (c(∇_d) − 1) satisfies β₁ᶜ ≤ 2W (Lemmas 1–16), and (ii) μ(I_S) = β₁ᶜ (Lemma 0).
Formalized: (i) in full (`SemigroupBetti.GenData.beta1_le_two_W`), and the half of (ii) needed for the theorem,
`spanRank (I_S) ≤ β₁ᶜ` (`SemigroupBetti.GenData.spanRank_le_beta1_of_n_eq`, via an explicit generating set of binomials
indexed by graph components). Not formalized: the reverse inequality β₁ᶜ ≤ μ(I_S) (equality), and sharpness of the bound.
